# BloodLink - Smart Blood Donation Coordination System

## Repository Structure
```
BloodLink/
├── mobile-app/       React Native + TypeScript donor application
├── web-dashboard/    React + TypeScript institution/admin dashboard
├── backend/          Node.js + Express + TypeScript REST API
├── database/         Schema, migrations, and seed data
├── docs/             Architecture diagrams, API docs, test evidence
└── .github/          Issue templates, PR template, CI workflows
```

## Getting Started
See `docs/CONTRIBUTING.md` for branching rules and setup instructions per module.

## Tech Stack
- Mobile: React Native + TypeScript
- Web: React + TypeScript
- Backend: Node.js + Express + TypeScript
- Database: PostgreSQL + PostGIS
- Notifications: Firebase Cloud Messaging
- Maps: Google Maps Platform
